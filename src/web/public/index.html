Sobre Preços e Cupons

Preços: Os valores exibidos são os preços reais da API do Mercado Livre, incluindo preço original e com desconto quando disponíveis.

Cupons: O Mercado Livre não disponibiliza cupons via API — eles são aplicados automaticamente no checkout. As postagens incluem uma nota orientando os compradores a verificar se há cupom disponível na página do produto.

Frete grátis: Identificado corretamente pela API e destacado nas postagens quando disponível.

🤖 Provedor de IA

Escolha qual IA gera os títulos chamativos dos posts. Configure a chave de API do provedor desejado e selecione o modelo.

Obtenha em console.anthropic.com
Obtenha em platform.openai.com/api-keys
Obtenha em aistudio.google.com

Como funciona

1. A IA gera um título chamativo curto (ex: "Para usar na pelada de sábado") baseado no nome do produto.

2. Esse título aparece em destaque no post enviado para os grupos.

3. Se nenhuma chave for configurada, o bot usa o próprio nome do produto como título.

Custo estimado: ~0,001 centavos por produto com modelos baratos (gpt-4o-mini, gemini-flash, claude-haiku).
